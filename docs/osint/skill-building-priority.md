# OSINT Pilot Selection Policy

A challenge enters the pilot only when it satisfies every evidence gate:

- complete public evidence assets;
- immutable private ground truth and typed verifier specification;
- safety/privacy review;
- provenance and license record;
- source retrieval date and archived fallback;
- reviewed compatible variants and decoys;
- completed playtest with recorded timing;
- deterministic build and public/private leak checks.

Skill transferability, method depth, tool authenticity, and independent corroboration remain useful ranking criteria, but they cannot compensate for missing evidence.

The legacy proposal bank did not meet the evidence gate because its referenced source packages are absent. Its 42 neutral skill concepts are archived in [`archive/legacy-idea-bank.json`](archive/legacy-idea-bank.json), without placeholder answers or storyline. The first releasable pilot therefore uses only the three reviewed dossiers currently supplied by `ctfgen-family-osint`.

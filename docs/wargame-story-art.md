# Wargame Storyboard: Captured Art

Per-level art drawn against the prompts in [`wargame-story.md`](wargame-story.md) -- one piece per level, following that level's story beat and title.

**Status: proposal, not shipped.** Nothing in this file is wired into any Dockerfile or banner generator. The banners players currently see are still the programmatic storyboard (chapter boxes, transmission strips, depth shafts) described in [`wargame-themes.md`](wargame-themes.md). This file exists so the story-driven art can be reviewed as a complete set before deciding whether to adopt it, and which pieces need rework.

All pieces obey the shared constraints in `wargame-story.md`: single-width characters only, <= 80 columns per line, and no text or imagery naming any command, tool, payload, or solving step. Rendering depends on the viewer's font -- these use box-drawing and block-element glyphs, so a font with poor coverage will show gaps.

# OSINT Instructor Material

Instructor solutions and canonical answers are not maintained in this repository. They are private artifacts in the reviewed `ctfgen-family-osint` dossier selected for the build.

The CEI adapter derives each generated CTFd flag from the dossier's typed verifier specification and copies no private solution or ground-truth artifact into player-downloadable files. Organizers should inspect the installed plugin's reviewed provenance and solution materials before changing the track state to `visible`.

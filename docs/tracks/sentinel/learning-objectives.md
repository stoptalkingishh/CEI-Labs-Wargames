# Sentinel Learning Objectives

Sentinel is a planned Security Operations SSH track. This non-staged pilot
contains Start Here and labs 01-05. Labs 06-21 remain planned and are not
available in this implementation. Labs 22-27 are non-staged, offline expansion
exercises; they do not alter that roadmap or imply a staged release.

- Start Here: connect through SSH and follow contained-lab engagement rules.
- 01 Asset Census: reconcile inventory, software, services, and ownership evidence.
- 02 Control Review: classify safeguards by category and purpose.
- 03 Change Window: identify the approval, testing, and rollback evidence required for a safe change.
- 04 Certificate Trail: evaluate identity, revocation, and key-protection evidence.
- 05 Attack Surface: distinguish observed listeners from configuration exposure and hardening evidence.
- 22 Phishing Header Analysis: identify sender-path inconsistencies from static email authentication and Received headers.
- 23 Detection Rule Validation: interpret a fixed rule's deterministic decision against a committed log corpus.
- 24 Endpoint Enrollment Evidence: corroborate simulated endpoint enrollment, key lifecycle, and inventory evidence.
- 25 Alert Triage Summary: confirm an evidence-supported root cause from a deterministic local summary.
- 26 Network Inventory Review: identify an unauthorized synthetic device from static ARP/DHCP and zone-policy evidence.
- 27 Evidence Metadata Review: review bounded document metadata, checksum, and extraction evidence.

The scenarios are defensive, local-only exercises. They do not teach privilege
escalation, lateral movement, network scanning, live-service interaction, or use
of external AI systems.

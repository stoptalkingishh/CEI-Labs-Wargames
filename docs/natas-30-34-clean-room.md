# Natas 30-34 Clean-Room Scenarios

Levels 30-34 are bounded, per-team training models. They release only the
adjacent material on their intended route; Natas 34 releases `natas34final`
only through its terminal debrief route and has no successor credential.

| Level | Objective | Safety boundary |
| --- | --- | --- |
| 30 | Repeated parameters can propagate types. | Fixed parser and mock query model; no database. |
| 31 | Legacy multipart ambiguity must not become file access. | Allowlisted virtual artifacts only. |
| 32 | Command-shaped input can be modeled safely. | Fixed command emulator; no interpreter or process. |
| 33 | Metadata is a trust boundary. | Inert registry with no file bytes or executable upload. |
| 34 | Complete and debrief the range. | Terminal route only; no next credential. |

`scripts/runtime_audit_natas_30_34.py` verifies wrong authentication, intended
and negative paths, secret isolation, and terminal behavior against loopback.

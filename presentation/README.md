# Presentation Sources

Reusable participant and facilitator presentation source belongs here. Decks
must be rebuilt from the current catalog before each event; do not reuse a
historical binary deck without checking its track scope and launch flow.

- `kickoff-brief.md` is the participant kickoff outline and speaker notes.
- `game-guide-brief.md` defines the per-track guide deck contract.
- `../docs/staged-game-operations.md` is the staff source for stage controls,
  scoring, and rehearsal.

The 2026-08-06 event repository retains its original PowerPoint files as
historical artifacts. Those decks describe an older Natas catalog and are not
the source for a current release.
